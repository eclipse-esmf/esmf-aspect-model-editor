= Generate AASX/XML/JSON

To generate AASX/XML/JSON files from an Aspect Model, proceed as follows:

* Click the xref:getting-started/ui-overview.adoc#menu-generate[Generate menu] and select *AASX/XML/JSON*.
+
image:generate-aasx.png[Generate AASX/XML/JSON, width=15%]

* Select *AASX*, *XML*, or *JSON* in the *Output file format* drop-down.
* Click *Generate* and store the file locally.
+
image:generate-aasx-dropdown.png[AASX/XML/JSON generation, width=30%]

TIP: If you run into errors, please make sure that the graph is valid. +
If the invalid element is not highlighted with a red border, click the Validate icon to get a hint.
