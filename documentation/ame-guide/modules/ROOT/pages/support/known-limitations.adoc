[[known-limitations]]
= Known limitations

All known limitations of the Aspect Model Editor, that is, features or improvements that are not yet implemented, are listed here.

See also xref:support/known-issues.adoc#known-issues[Known issues].

[[current-known-limitations]]
== Current limitations related to the SAMM Aspect Meta Model

This section lists features that are supported in Aspect Models by the SAMM Aspect Meta Model but not fully or only partially available within the Aspect Model Editor.

[cols="15%,30%,55%"]
|===
| Category | Title | Explanation

| SAMM
| Entity: Include predefined instance
| SAMM supports to refer to a globally pre-defined Entity instance (namespace: `samm-e`), but the Aspect Model Editor does not.

| SAMM
| Properties: Refinement
| It is not possible to refine Properties to make sharing of Entities easier.
|===

[[current-known-limitations-ux]]
== Current limitations related to usability

This section lists features that can be achieved within the Aspect Model Editor, but with a substantial limitation in the usability.

[cols="15%,30%,55%"]
|===
| Category | Title | Explanation

| Usability
| Copy & paste
| Copy & paste of graph elements is not supported. The *Cut*, *Copy* and *Paste* commands of the Edit menu only apply to text input fields.

| Usability
| Undo & redo
| Undo & redo of the graph is limited to the last 25 changes per tab; moving shapes is not undone. See xref:getting-started/undo-redo.adoc#undo-redo-limits[Undo and redo].

| Usability
| Aspect Repository and Entity Repository
| This version of the Aspect Model Editor supports only file-based operations. Users also want to share Aspects and Entities for reuse.

| References
| Saving models with missing references
| An Aspect Model whose referenced elements are missing in the workspace can be opened, but not saved. See xref:namespace/missing-references.adoc[Aspect Models with missing references].

| References
| Missing elements of existing namespaces in the Workspace sidebar
| The Workspace sidebar only marks files that reference a missing *namespace*. A missing element of a namespace that exists in the workspace is only detected when the model is opened.

| Workspace
| Open models in other windows (browser)
| Only the desktop application knows which models are open in other windows. In the browser, deleting files and namespaces and clearing the workspace only consider the tabs of the current window.
|===

[[current-known-limitations-macos]]
== Current limitations on macOS

This section lists limitations that are specific to running the Aspect Model Editor on macOS.

[[macos-notarization]]
=== No notarization or code signing

The Tauri application is currently not notarized or signed with an Apple Developer certificate. As a result, macOS Gatekeeper blocks the app from starting and marks it as quarantined after downloading.

To run the application, use one of the following workarounds:

* Remove the quarantine attribute via Terminal:
+
[source,bash]
----
xattr -r -d com.apple.quarantine "/Applications/Aspect Model Editor.app"
----

* Allow the app manually via *System Settings* -> *Privacy & Security*: after the first blocked launch attempt, scroll down to the security section and click *Open Anyway*.

For installation steps on macOS, see xref:installation.adoc#install-mac[Install the Aspect Model Editor on Mac].
If the application starts but the backend service does not work, see xref:support/known-issues.adoc#macos-app-cannot-be-opened[macOS: Application cannot be opened or backend does not start].
