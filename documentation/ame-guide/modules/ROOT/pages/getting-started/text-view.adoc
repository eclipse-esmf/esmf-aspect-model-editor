[[text-view]]
= Aspect Model text view

Besides the graphical editor, the Aspect Model Editor can show the current model as Turtle (TTL) text.
This shows you which TTL the graphical editor writes, for example if you also edit your models in a text editor such as VS Code.

[[text-view-switch]]
== Switch between graph and text

Use the switch at the right end of the xref:getting-started/ui-overview.adoc#editor-tabs[tab bar]:

* *Edit*: the graphical editor
* *Aspect Model*: the text view of the model

There is no separate menu entry or keyboard shortcut for switching between these two views.

The view is remembered per tab. When you switch to the text view, an open Edit dialog, the element search and the sidebar are closed, because the text view uses the full width of the editor.

[[text-view-content]]
== What the text view shows

The text is created the same way as when the model is saved: the current state of the editor, *including unsaved changes*, is formatted by the backend.
The element order and the header comment are applied as described in xref:getting-started/preserve-ttl-structure.adoc[Keep the structure of TTL files].

* The text has line numbers, syntax highlighting and folding.
* The header shows the number of lines and the number of validation issues of the last validation.
  Lines with validation issues are marked in the gutter.
  Click the issue counter to jump to the next issue.
* If the backend formatter is not available, the raw serialization of the model is shown and marked as *Unformatted*.
* If one graph element is selected when you open the text view, the text scrolls to the statement of this element.

NOTE: The text view is *read-only*. To change the model, switch back to *Edit*. The text is updated automatically when you switch to another tab, change the model or change the prefixes. *Reload* creates it again on demand.

[[text-view-actions]]
== Actions in the text view

[cols="30%,70%"]
|===
| Action | Description

| *Search* (`Cmd/Ctrl+F`)
| Opens the search panel of the text.

| *Sort elements alphabetically*
| Sorts the elements of the model once by name; the Aspect stays at the top. Save the model to write the new order to the file. Not available while the element order is defined by the formatter (*Settings > Editor*).

| *Manage prefixes*
| Opens the prefix management of the model, see xref:getting-started/ui-overview.adoc#prefixes[Prefixes].

| *Reload*
| Creates the text again from the current state of the editor.

| *Copy to clipboard*
| Copies the complete text.
|===

[[text-view-limits]]
== Limitations

* The text cannot be edited.
* While the text view is shown, the actions of the toolbar that work on the graph (e.g. zoom, format, filter, connect, delete) are disabled; validation and prefix management remain available.
* Comments inside the model and the formatting of single elements are created by the formatter. They can differ from the source file, see xref:getting-started/preserve-ttl-structure.adoc[Keep the structure of TTL files].
