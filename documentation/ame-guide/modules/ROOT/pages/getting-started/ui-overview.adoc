[[workspace-sidebar]]
== 3. Workspace sidebar

The Workspace sidebar &ndash; see screenshot below &ndash; allows you to access namespaces (2) and to drag and drop elements to the graph area canvas (1).

image::ame-ui-overview-workspace-numbers.png[width=60%]

Expand the Workspace sidebar to view the description of each element.

To add an element to your model drag and drop it on the graph area canvas, edit its details, and connect it with the rest of the graph.

For more information, see xref:getting-started/edit-models.adoc[Edit models].

[[graph-area]]
== 4. Graph area canvas
This is the space where your Aspect Model is visualized. You can easily navigate it in the graph area canvas using the Minimap. 

To show or hide it, click the Toggle Minimap icon image:toolbar-icons/map.png[Map toggle icon] in the upper right corner of the graph area canvas.

Alternatively, you can also use the *Toggle Minimap* option in the xref:getting-started/ui-overview.adoc#menu-view[View Menu].

image:mini-map.png[Map toggle icon,50%]

For more information, see xref:getting-started/navigate-models.adoc[Navigate models].

[[edit-dialog]]
== 5. Edit dialog

Edit the attributes of a selected element of your Aspect Model with the Edit dialog.

How to access the details of an element in the Edit dialog: 

* Double-click the element.
* Select the element and right-click to open the context menu. Then select *Open in detail view* image:toolbar-icons/jump.png[Edit icon].
* Select the element and click the *Edit highlighted cell* button image:toolbar-icons/jump.png[Edit icon] on the xref:getting-started/ui-overview.adoc#toolbar[toolbar].

At the bottom of the Edit dialog, the lists *Incoming edges* and *Outgoing edges* show all elements that are connected to the edited element.
Use the buttons of an entry to locate the element in the graph area canvas, open it in the Edit dialog, or &ndash; for elements from another file &ndash; open it in a new tab.
These lists, as well as the connection-related fields (e.g., the data type of a Characteristic), are updated immediately when you add or remove connections in the graph area canvas while the Edit dialog is open.

For more information, see xref:modeling/edit-elements.adoc[Edit elements].

{nbsp}
[[editor-tabs]]
== 6. Editor tabs

The Aspect Model Editor can keep several models open at the same time.
Each opened model is shown as a tab in the tab bar above the graph area canvas.

* The tab shows the file name of the model. Hover over a tab to see its namespace and file name.
* A dot next to the file name indicates that the model has unsaved changes.
* Click a tab to switch to that model. The open Edit dialog of a tab is restored as well.
* Click the *+* button to open a new tab with an empty model (`new-model.ttl`, `new-model-2.ttl`, ...).
* Click the *x* button of a tab to close it. If the model has unsaved changes, you are asked whether you want to save them first.
When you close the last tab, a new empty model is opened.
* Opening a model that is already open (e.g., from the Workspace sidebar) switches to its existing tab instead of opening it twice.
* Loading a model while an untouched empty model tab is active replaces that empty tab.
* If there are more tabs than fit into the tab bar, use the arrow buttons or the mouse wheel to scroll through them.
