[[shared-models]]
= Element libraries (models without an Aspect)

An "element library" is an Aspect Model file that does not contain an Aspect element.
It lets you define model parts (for example Properties, Characteristics, Entities or Units),
which can be reused in multiple other models.

NOTE: Element libraries were previously called "shared models" in the Aspect Model Editor.

TIP: In case you want to extract a part of an Aspect Model graph into an element library, please make sure to delete the Aspect element from the model. Creating element libraries proves advantageous, particularly when developing broadly defined elements for use in various Aspect Models.

After deleting the Aspect element, you can choose a new file name to describe the resulting element library.
This file can then be saved in the workspace like any other ttl file.

image:shared-model-file-name.png[Declare the name of the element library,width=40%]

As a result, you create a valid ttl file, which just does not contain the "Aspect" element.
From all other points of view the lifecycle of such a model is similar to the one of an Aspect Model.

image::shared-model-view.png[, 65%]

Such a model can be referenced from multiple other element libraries and Aspect Models.
As soon as you define such a reference, the element library is treated like a dependency from the Aspect Model's perspective.

When using an element library, the process is the same as with references, see xref:namespace/use-references.adoc[Use references].

image::use-shared-models.png[, 65%]

TIP: In case you need to convert an element library into an Aspect Model, simply add an Aspect element as the first element in the graph.
